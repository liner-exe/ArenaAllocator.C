# ArenaAllocator.C (lnr_arena)

Fast, zero-dependency, 8 byte aligned single-header Arena Allocator library for C/C++

## How to Use
1. Drop .h file into your project source
2. Follow "Before You Start" below 

## Before You Start
```c
// Do this ONLY ONCE in .c/.cpp file
#define LNR_ARENA_IMPLEMENTATION
#include "lnr_arena.h"

// Anywhere else just include header file
#include "lnr_arena.h"
```
